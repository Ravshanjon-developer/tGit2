# Cleaning X — landing page

![Cleaning X — landing page](screenshots/desktop.png)

**🇷🇺** Учебная вёрстка лендинга клининговой компании по макету из Figma.

**🇬🇧** Cleaning company landing page built from a Figma design (learning project).

**Стек / Stack:** HTML, Tailwind CSS

## Запуск / Run

```bash
npm install
npx tailwindcss -i ./src/input.css -o ./src/output.css --watch
```

Откройте / open `src/index.html` в браузере.
